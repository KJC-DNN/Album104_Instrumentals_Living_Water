# Living Water — Instrumentals for Album 104
Fourteen instrumental tracks for Album 104. No vocals. Thirst for the Living Water. Eyes waiting. Spirit thirsty. Hunger growing. Living water that quenches. Presence enough. Name enough. Quiet worship. Open plain, still waters, empty wooden cross. Not a replacement for the vocal album.
